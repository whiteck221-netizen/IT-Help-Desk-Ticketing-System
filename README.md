# IT-Help-Desk-Ticketing-System
IT Help Desk Ticketing System

Project Overview

This project is a simulated IT Help Desk Ticketing System designed to demonstrate foundational IT support, troubleshooting, customer service, and ticket management skills.

The project includes 10 simulated support tickets covering common IT issues and practical troubleshooting scenarios.

Project Objectives

- Practice documenting IT support requests.
- Identify and prioritize technical issues.
- Apply troubleshooting methodologies.
- Develop clear customer communication.
- Understand help desk ticket management.

Skills Demonstrated

- IT troubleshooting
- Ticket documentation
- Incident prioritization
- Customer service
- Problem-solving
- Technical communication

Ticket Categories

The project includes 10 simulated tickets addressing common IT support situations.

Priority Classification

Tickets are organized using priority levels to demonstrate how IT support teams evaluate urgency and business impact.

Project Documentation

- 10 simulated help desk tickets
- Master ticket summary
- Ticket priority guide
- Project conclusion

Learning Outcomes

This project strengthened my understanding of IT support workflows, troubleshooting, documentation, and customer service.

It also allowed me to apply my communication background from the University of Tennessee to technical support scenarios.

Disclaimer

All tickets and scenarios in this project are simulated for educational and portfolio purposes.
